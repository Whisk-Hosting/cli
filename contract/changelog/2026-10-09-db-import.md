# whisk db import

`whisk db import <dump file> [--swap] [--wait]` loads a `pg_dump -Fc` file of another database
into the app's database, beside the live one or swapped in. `POST /orgs/:org/apps/:app/db/imports
{bytes}` authorises the upload; `POST .../restore` takes `import` in place of `at`, and a restore
record carries `import` and omits `at` for an import. SKILL.md says how to move an existing
database in.

# Functions run on Inngest 1.46

The engine that runs apps' functions moves from Inngest 1.44.0 to 1.46.0 on the platform, in the
laptop stack, in `whisk dev` and in the contract stub, so an app is developed against the
version it runs on. The skill, the workflow reference and the public CLI README name 1.46.0.
1.45 changed Inngest's API V2 to answer HTTP 400 for parameters it does not support; the control
plane uses the V1 REST API and GraphQL, which that does not touch.
